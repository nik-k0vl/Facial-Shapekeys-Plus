v2.2.0
    - MINOR
        • Reworked the face tracking auto-folder system: "Add ARKit Blend Shapes" now creates its shapes
            inside a "---ARKit---" folder, and "Add Unified Expressions Blend Shapes" inside a
            "---Unified Expressions---" folder - both nested under a shared "---Face Tracking---" root folder.
            "---Blended Shapes---" is now a sibling of "---Unified Expressions---" (rather than nested inside
            it), created immediately after it so it's positioned below it.
        • Added "Add Custom Blend Shapes", which creates the addon's curated custom Unified Expressions preset
            (in its own order, with its own exclusions) using the same "---Face Tracking---" folder structure.
        • Added "Add Visemes", which creates the 15 Oculus/VRChat visemes in a standalone "---Visemes---"
            folder (not nested under "---Face Tracking---").
        • Added "Translate ARKit → Unified Expressions" and "Translate Unified Expressions → ARKit", which
            duplicate existing blend shapes and rename the duplicates to their equivalent in the other
            standard, using VRCFaceTracking's official ARKit compatibility table. Results are parented to a
            "---Unified Expressions---" or "---ARKit---" folder (under "---Face Tracking---"), with
            Unified Expressions results that belong to "Blended Shapes" routed there automatically.
        • Shift+Click and Ctrl+Click on a shape key's selection checkbox now both select every shape key
            between the active row and the clicked one (inclusive), in addition to the existing selection.

v2.1.0
    - MINOR
        • Added "Copy Shape Key, Inverted", which duplicates the active/selected shape key(s) and inverts
            the result relative to its relative key (equivalent to blending it to a value of -1 and baking that).
        • Added "Add ARKit Blend Shapes", which creates all 52 standard (empty) ARKit blend shapes and
            automatically parents them to a "---Face Tracking---" folder.
        • Added "Add Unified Expressions Blend Shapes", which creates the Unified Expressions standard's
            Base Shapes and Blended Shapes (empty), parenting them to a "---Face Tracking---" folder and a
            nested "---Blended Shapes---" folder, respectively.
        • Mirrored copies/duplicates now use Blender's own `bpy.utils.flip_name()` to detect and rename the
            Left/Right side of a shape key's name, instead of only recognizing a ".L"/".R" suffix. This also
            applies to the standalone "Mirror Shape Key" operator.
        • Renamed "New Shape From Mix" to "New Combined", matching Blender's own terminology. When used with
            a group of selected shape keys, each selected shape key is now temporarily forced to a value of
            1.0 while combining, so a full-strength combined shape key is created even if some (or all) of the
            selected shape keys currently have a value of 0.

v2.0.0
    - MAJOR
        • The add-on now utilizes a robust tree hierarchy internally, so folders can be multi-selected.
        • Extended the "Copy Shape Key" operator to copy drivers and, optionally, override specific properties.
        • The add-on has been organized into multiple Python modules under the `shape_keys_plus` package.
        • The add-on has been fully translated to Japanese.
            To add/modify translations, see the Japanese implementation in `shape_keys_plus/core/translations.py`.

    - MINOR
        • The "Mirror Shape Key" operator has been replaced with one that's compatible with folders and multi-selection.
        • To save a bit of horizontal space, the sidebar's context menus and operator buttons have been merged.
            To access a context menu, click and hold (or drag) the respective operator button.
        • The debug operator "Mutate Folder" is now available via search menu.
        • The normal shape key icon is now hidden to make folders easier to see,
            but can be changed back to any icon in the add-on preferences.
        • Folders icons explicitly set to the default pair will now be updated automatically.
        • Moved the settings for the default folder icon to the add-on preferences,
            so they will persist between projects.

    - PATCH
        • Fixed the Rotation Mode property being reset upon driver variable sorting operations.
        • Fixed inability to retain driver variable data when DriverTarget.id is set to a non-Object.
        • To further speed up shape key operations, the object will be temporarily hidden. This allows all
            operations to be executed in bulk before updating the mesh, meaning performance issues are no
            longer proportional to how many shape keys you have, but rather how long it takes to hide/unhide the object.
            This can be further rectified on the user's end by hiding intense modifiers such as Subdivision.
