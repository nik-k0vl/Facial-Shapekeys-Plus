Facial-Shapekeys++ improves the ShapeKeys+ folder workflow with these changes:

- **Folder-aware mesh joining:** Ctrl+J merges equally named shape key folders, including nested
  folders and joins of more than two meshes. The active mesh's hierarchy and folder settings take
  precedence when the same shape key has conflicting parents.
- **Shift-click checkbox selection:** Check a starting key, then Shift-click another checkbox to
  select the inclusive range. Existing selections stay checked, and repeated Shift-clicks keep
  the starting key, including after reordering.
- **Alphabetical sorting:** The downward-arrow menu includes **Sort Selected A to Z** and
  **Sort Selected Z to A**. At least two checked keys are required. Sorting ignores capitalization,
  uses the selected sibling positions, and operates separately inside each parent folder.
  Selected folders move with their contents. The Basis, active key, checkbox selections, and
  Shift-click starting key are preserved.
- **Credits:** Michael Glen Montague is credited as the original author; MooshPaw and xonxt are
  credited as maintainers with AI-coded contributions. Full credits appear on separate lines in
  the add-on preferences.

Download **Facial-Shapekeys-Plus.zip** from this release's assets and install it through
**Blender Preferences > Add-ons**, then enable **Facial-Shapekeys++**. Restart Blender after
replacing an earlier version.

Validated in Blender 5.0: 47 tests covering folder joining, selection, sorting, and undo/redo.
The release ZIP contains only the add-on runtime files, configuration, and license.
